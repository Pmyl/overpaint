# Overpaint
Little presentation tool where you can quickly draw lines, arrows and text on your screen.

## Controls
| command | action |
| --- | --- |
| Left click | draw line |
| Ctrl+left click | draw arrow |
| Alt+left click | draw straight line |
| Just type on your keyboard | draw text on a sticker (then *=> click* to apply) |
| Scroll wheel | scroll through colours |
| Ctrl+scroll wheel | change brush/text size |
| Right click | erase entire shape |
| Ctrl+z | undo |
| Escape | close |
